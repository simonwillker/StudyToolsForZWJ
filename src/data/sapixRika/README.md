# Sapix 理科 問題データ（小4 冬期講習相当）

「Sapix 理科」（`src/SapixApp.jsx` を `subjectId="sapixRika"` で使う）の問題データです。**すべてオリジナル問題**で、他社教材の問題文・図・本文は写していません。

- `meta.json`：分類（色）と単元の一覧（生物・地学・物理・化学の10単元）。
- `<単元id>.json`：単元ごとの問題。**各単元ちょうど 20 問**、易→難（基本 8・標準 8・発展 4）の順。

## スキーマ

ファイル全体と各問題の形は算数（`src/data/sapixMath/README.md`）と同じです。算数とのちがい：

| フィールド | 説明 |
|---|---|
| `type` | `choice`（選択肢）/ `text`（記述）/ `number`（数値）。 |
| `choices` / `answer` | `choice` のとき。`answer` は正しい選択肢の番号（0 から）。**画面では選択肢を毎回並べかえて出す**ので、正解を先頭に書いてかまいません。 |
| `fixedOrder` | `true` にすると並べかえない（文の中の言葉を順に並べた選択肢など、順番に意味があるとき）。 |
| `accepted` | `text` のとき、正解として受けつける答えの配列。1つ目が画面に出す模範解答。判定では空白・句点・全角半角の差を無視し、カタカナはひらがなとして比べます。 |
| `passage` | 読解の問題で、単元ファイルの `passages` にある本文の id。本文は問題の上に表示されます。 |
| `calc` | 使いません（正解を計算で確かめられないため）。 |

単元ファイルの `passages`：`{ "<id>": { "title": "題名", "text": "本文（\n で改行・段落の頭は全角スペース）" } }`

## 検証

```bash
npm run validate:sapix-subjects   # 国語・社会・理科
npm run validate                  # すべて
```

必須項目・id の一意（3教科をまたいで）・各単元 20 問・難易度の順・選択肢の重複・正解番号の範囲・記述の正解の形（読みはひらがなだけ、書きにカタカナが残っていない）・本文の参照を確かめます。
