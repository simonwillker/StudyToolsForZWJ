# Sapix 算数 問題データ（小4 冬期講習相当）

「Sapix 算数」（`src/SapixApp.jsx` を `subjectId="sapixMath"` で使う）の問題データです。
**すべてオリジナル問題**です。SAPIX や他社教材の問題文・図・数値は写していません（単元の典型パターンと難易度だけを参考にしています）。

- `meta.json`：分類（色）と単元の一覧。単元一覧の並び順はここで決まります。
- `<単元id>.json`：単元ごとの問題。**各単元ちょうど 20 問**、易→難（基本 8・標準 8・発展 4）の順に並べます。

| 分類 | 単元（ファイル） |
|---|---|
| 数と計算 | 計算のくふう（kufu）、約数と倍数（yakusu）、分数の計算（bunsu） |
| 文章題 | 和差算（wasa）、分配算（bunpai）、つるかめ算（tsurukame）、植木算（ueki）、周期算（shuki）、過不足算（kabusoku）、年令算（nenrei） |
| 図形 | 角度（kakudo）、三角形・四角形の面積（menseki）、立体（rittai） |
| 規則性・場合の数 | 規則性（kisoku）、場合の数（baai） |

## スキーマ

### meta.json

```json
{
  "categories": [{ "id": "keisan", "label": "数と計算", "color": "#2F5D8A" }],
  "units": [{ "id": "kufu", "label": "計算のくふう", "category": "keisan", "file": "kufu.json" }]
}
```

### 単元ファイル

```json
{
  "unit": "kufu",
  "questions": [
    {
      "id": "sm-kufu-01",
      "level": "基本",
      "type": "number",
      "q": "くふうして計算しましょう。\n37 ＋ 48 ＋ 63",
      "answer": 148,
      "unit": "",
      "calc": "37+48+63",
      "explain": "37 と 63 をたすと、ちょうど 100 になります。\n…"
    }
  ]
}
```

| フィールド | 必須 | 説明 |
|---|---|---|
| `id` | ○ | 全単元で一意。`sm-<単元id>-<2けた連番>`。学習記録・復習リストのキーなので、出したあとは変えない。 |
| `level` | ○ | `基本` / `標準` / `発展`。ファイル内でこの順に並べる。 |
| `type` | ○ | `number`（数値入力）/ `fraction`（分数入力）/ `choice`（選択肢）。 |
| `q` | ○ | 問題文。`\n` で改行。`2/7` や `1と2/5` は画面で縦書きの分数になる。 |
| `answer` | ○ | `number`：数値（小数可）。`fraction`：約分済みの仮分数の文字列（例 `"19/12"`。整数になる答えは `number` にする）。`choice`：正しい選択肢の番号（0 から）。 |
| `unit` | – | 答えの単位（`cm²`、`通り` など）。入力欄の右に出る。 |
| `choices` | `choice` のみ | 選択肢の文字列の配列。 |
| `form` | – | `fraction` のみ。`mixed`（帯分数で答える）/ `improper`（仮分数で答える）。省くとどちらでも正解。 |
| `calc` | ○ | **検算式**（JavaScript の式）。解説とは別の方法（ふつうの計算・総当たり）で答えを出し、`answer` と一致するかを検証スクリプトが確かめる。`choice` は正しい選択肢の文字列を返す。 |
| `explain` | ○ | 小4 にも分かる解き方（途中式つき）。`\n` で改行。 |
| `figure` | – | 図。`viewBox` つきのインライン SVG 文字列（`<svg …>…</svg>`）。スクリプトやイベント属性は入れない。図なしで成り立つ問題を優先する。 |
| `figureAlt` | 図があるとき | 図の説明（読み上げ用）。 |

`calc` で使える道具：`R("1/2+1/3")`（分数のまま計算）、`gcd` `lcm` `range(a,b)` `sum` `count(配列, 条件)` `divisors(n)` `find(条件, a, b)`（条件を満たす最初の整数）`perms(配列, k)` `combs(配列, k)` `uniq(配列)` `DAYS`（日〜土）。

## 判定のきまり

- 数値：全角数字・カンマも受けつけ、値が等しければ正解。
- 分数：整数部分・分子・分母の 3 つの欄。値が等しく、分数部分が約分されていれば正解（帯分数でも仮分数でもよい）。`form` があるときはその形でないと「答えは合っています」と表示して不正解にする。

## 検証

```bash
npm run validate:sapix-math   # このデータだけ
npm run validate              # 英検・CCAO-F とまとめて
```

必須項目・id の一意・各単元 20 問・難易度の順・正解の型・図の形式を調べ、**全問の `calc` を実行して正解を検算**します。
