# StudyToolsForZWJ

2つの学習アプリをまとめたリポジトリです。起動すると最初にアプリ選択画面が表示されます（選んだアプリは `localStorage` に記憶され、次回はそのまま開きます）。

- **きょうのドリル（Daily Drill）**：小学生向けの日常学習ドリル
- **英検マスター（EIKEN Master）**：英検5級〜1級対応の総合学習アプリ
- **Claude 認定**：Claude 認定資格の対策。中で資格を選ぶ（CCAO-F：Associate – Foundations／CCAR-F：Architect – Foundations。CCDV-F・CCAR-P は準備中）
- **Sapix**：学年 → 科目（算数・国語・理科・社会・英語）→ 単元の順に選ぶ。いまは4年（算数・国語・社会・理科は小4 冬期講習相当、英語は英検5級〜4級程度）。算数 19 単元・国語 12 単元・社会 15 単元・理科 15 単元・英語 10 単元（各 20 問、計 1,420 問、オリジナル問題）

## 勉強者の選択と勉強履歴

- **勉強者を選んでから始める**：起動するたびに「だれが勉強しますか？」の画面で **ZWJ / ZY / Guest** から選びます（`src/learner.js`）。選んだ人はそのタブのあいだ覚えていて、アプリ選択画面の「勉強者を切りかえる」で変えられます。アプリの中では画面左下に今の勉強者が出ます。
- **学習記録は勉強者ごと**：英検マスター・Claude 認定（資格ごと）の学習記録・復習リスト・模試結果は、勉強者ごとに別々に保存されます。ZWJ はこれまでと同じ保存先を使うので、今までの記録はそのまま ZWJ の記録になります（ほかの人は `<キー>::ZY` のように名前つきのキー）。
- **勉強履歴（📅）**：テスト1回ごとに記録します（`src/studyLog.js`、365日分）。アプリ選択画面の「📅 勉強履歴」で見られ、タブでほかの勉強者の履歴にも切りかえられます。表示する内容は次のとおりです。
  1. **勉強者**（画面上部とタブ）
  2. **日付・時間**（日ごとに、その日の勉強の時間帯。各回の始めと終わりの時刻）
  3. **勉強内容**（アプリ＋内容。例：英検マスター／3級 単語・熟語、きょうのドリル／算数 4年 計算、CCAO-F／模擬試験）
  4. **テスト回数**（その日のテストの回数と、同じ内容の「第N回」）
  5. **⭕❌**（各回の正解・不正解の数と、1問ごとの ⭕❌ の並び）
  - 各アプリは出題を始めるときに `newStudySession()` を呼んで回を区切ります。呼び忘れても、内容が変わったときと30分以上あいたときは新しい回になります。
  - 勉強履歴を記録し始める前の日は、英検マスターの問題ごとの履歴（⭕❌・時刻つき）から回を組み立て、残りは日別合計から「内訳なし」として表示します（CCAO-F は日別合計のみ）。

## きょうのドリル（Daily Drill）

小学生向けの日常学習ドリル用 React コンポーネントです。もともと Claude.ai の Artifacts（アーティファクト）機能上で作成・反復改良してきたものを、GitHub で管理できる形にパッケージしました。

### 収録コンテンツ

- **算数**：学年（小3〜6）・問題類型（計算／文章題・図形）・問題数（20/35/50問）を選んで計算ドリルを自動生成
- **理科 / 社会**：学年（小3〜6）・問題数（20/35/50問）を選べる4択形式
- **国語**：一問一答形式（学年タグ付き）
- **英語**：英検2級レベルの語彙・文法4択
- **英検2級 単語テスト**：400語を20語ずつ、好きな範囲でテスト
- **カスタム単語テスト**：自分で入力した英単語（最大35語）で「意味を入力／英語を書く／聞き取り／穴うめ英作文」の4形式
- **カスタム漢字テスト**：自分で入力した漢字・言葉（最大35語）で「読み方／書き取り／穴うめ作文」の3形式
- 出題ローテーション（直近のテストに出た問題をなるべく避ける仕組み）

## 英検マスター（EIKEN Master）

日本の英検（実用英語技能検定）5級〜1級に対応した学習アプリです（`src/EikenApp.jsx`）。級を選ぶと、分野別の7モード＋本番形式の模擬テストから選べます。

### 学習モード

- **単語・熟語**：4択クイズ。英語→日本語／日本語→英語の出題方向と、20語ずつの出題範囲（組）を選べる。発音ボタンつき
- **常用短句**：会話でそのまま使える定型表現・句動詞・慣用表現を、級ごとに100個ずつ。「クイズ」（4択、英語→日本語／日本語→英語）と「カード」（1つずつ表示し、タップで意味・使う場面・例文を見る）を切りかえられる。20個ずつの出題範囲（組）つき。クイズの結果は学習記録と復習リストに入る
- **文法・穴うめ**：空所補充の4択問題。文法ポイントの解説と全文訳つき
- **長文読解**：英文パッセージ＋内容一致の4択問題（読み上げボタンつき）
- **リスニング**：ブラウザ標準の読み上げ（Web Speech API）で英文を聞き、内容について答える。スクリプトと訳は回答後に表示
- **会話文**：2人の会話の空所に入る最も自然な発言を選ぶ。会話全体を通し読みする再生ボタンつき（回答前は空所をスキップし、先読みを防止）
- **発音練習**：単語の発音をお手本（TTS）で聞き、マイクに向かって発音し、認識結果とスコアでフィードバックを受ける（`SpeechRecognition` 対応ブラウザのみ）。出題範囲（組）で単語をしぼれる
- **模擬テスト**：過去問（一次試験）の大問構成どおりに1回分を通しで受験する（下記）

### 模擬テスト（本番形式）

5級〜1級それぞれについて、**過去問の一次試験と同じ大問構成**で1回分を通しで受験できます（`src/EikenTest.jsx`）。

- **本番モード**：筆記・リスニングそれぞれに制限時間つき。解答中は正誤を表示せず、提出後にまとめて採点します。リスニングの放送回数は本番と同じ（3級以下2回／準2級以上1回）に制限され、第1部では選択肢も画面に表示されません（本番は放送のみ）。筆記が終わるとリスニングに進み、筆記にはもどれません。
- **練習モード**：時間無制限。リスニングは何度でも再生でき、選択肢も表示されます。
- **解答一覧**：マークシートのような一覧から未解答・見直しフラグを確認し、問題間を移動できます。
- **採点結果**：総合正答率に加えて大問ごとの正答率、合格の目安（級ごとの想定正答率）との比較、最も取りこぼした大問のアドバイス、所要時間を表示します。受験履歴は `localStorage` に保存されます。
- **復習**：全問について、自分の解答・正解・全選択肢の解説・本文訳・リスニングのスクリプトを確認できます。「まちがえた問題だけ」に絞り込めます。

出題形式は級によって異なり、本番の構成に合わせてあります。

| 級 | 筆記 | リスニング | ライティング |
|---|---|---|---|
| 5級・4級 | 短文の語句空所補充／会話文の文空所補充／語句整序（4級は長文読解も） | 応答文選択・会話・文の内容一致 | なし |
| 3級 | 上記＋長文の内容一致選択 | 3部構成 | Eメール／意見論述 |
| 準2級 | 短文／会話文／長文の語句空所補充／長文の内容一致 | 3部構成（放送1回） | Eメール／意見論述 |
| 2級 | 短文／長文の語句空所補充／長文の内容一致 | 2部構成 | 英文要約／意見論述 |
| 準1級 | 短文／長文の語句空所補充／長文の内容一致 | 会話・文・RealLife形式 | 英文要約／意見論述 |
| 1級 | 短文／長文の語句空所補充／長文の内容一致 | 会話・文・RealLife・インタビュー | 英文要約／意見論述 |

ライティングは自動採点せず、**解答例と観点別チェックリストによる自己採点**です。

各大問には「収録問題数」と「本番の問題数」が併記されます。問題を追加して本番と同じ問題数に近づけられる設計で、追加はJSONへの追記だけで完結します（`src/data/eikenTest/README.md`）。

### 収録単語（5級〜1級）

3級・準2級・2級は各500語、それ以外の級は各200語、**計2,300語**を収録しています。1語ごとに発音記号・品詞・意味・例文（英日）がついています。
英検の語彙は累積なので、**同じ単語は複数の級に登録していません**（`CLAUDE.md` の「重複不要」方針）。

単語は**20語ずつの「組」**に分かれ、「単語・熟語」「発音練習」で組を選んで学習できます（1回20問）。

| 級 | 対象レベル | 語彙数のめやす（累積） | 収録語数 |
|---|---|---|---|
| 5級 | 中学初級程度 | 約600語 | 200語（10組） |
| 4級 | 中学中級程度 | 約1,100語 | 200語（10組） |
| 3級 | 中学卒業程度 | 約1,650〜2,100語 | 500語（25組） |
| 準2級 | 高校中級程度 | 約3,000〜3,600語 | 500語（25組） |
| 2級 | 高校卒業程度 | 約5,100語 | 500語（25組） |
| 準1級 | 大学中級程度 | 約7,500〜9,000語 | 200語（10組） |
| 1級 | 大学上級・社会人上級程度 | 約10,000〜15,000語 | 200語（10組） |

語彙数のめやすは英検協会の公式基準ではなく、英語教育で一般に使われている数値です。収録語は
各級で**最初に覚えるべき中核語**を選んだもので、めやす語数をすべて収録したものではありません。
`node scripts/addVocab.mjs <級> <JSONファイル>` で単語を追加でき、追加すると出題範囲（組）が自動的に増えます。

### 学習記録・解説について

- 正解・不正解にかかわらず、すべての選択肢の解説を毎回表示します（何が正解でどこが間違っていたかが必ずわかる設計）。
- 学習記録は `localStorage` に保存され、級ごと・モードごとの正答率と最終学習日時をいつでも確認できます（画面右上「学習記録」）。
- 出題データは分野別ドリルが `src/data/eikenApp/*.json`、模擬テストが `src/data/eikenTest/*.json` に分離されています。スキーマや追加方法はそれぞれの `README.md` を参照してください。
- データを追加したら `npm run validate` で検証できます（`validate:app` は単語・分野別ドリル、`validate:test` は模擬テスト）。

## Claude 認定（v1.33.0〜：CCAO-F と CCAR-F）

アプリ選択画面の「**Claude 認定**」1 枚から使います（v1.31.0 までの「CCAO-F 対策」カード）。中で資格を選び、どの資格も同じ画面（`src/claudeCert/CertApp.jsx`）で **ドメイン練習・模擬試験・考点讲义・考点別の成績と弱点練習・錯題本（今日の復習）・合格予測・頻出単語・音声読み上げ／音声モード・バックアップ** が使えます。

- **データの置き場所**：`src/data/claudeCert/<資格>/`（`meta.json`・`lessons.json`・`d1-*.json`…・`glossary.json`・`vocab.json`）。資格の一覧と画面の文言は `src/claudeCert/certs.js`。資格を足すときは、ここに 1 件足してデータのフォルダを置きます（CCDV-F・CCAR-P は一覧に「準備中」と出ています）。
- **学習記録は資格ごと・勉強者ごと**：キーは `<資格の頭>ProgressV1` など（`src/claudeCert/certState.js`）。**CCAO-F は以前の `ccaof*` キーのまま**なので、v1.31.0 までの学習記録・錯題本・模試の結果・頻出単語・バックアップファイルはそのまま使えます。CCAR-F は `ccarf*`。前回「CCAO-F 対策」を開いていた人は、初回は CCAO-F が直接開きます（アプリ id `ccaof` → `claudeCert` に移行）。
- 検証：`npm run validate:claude-cert`（全資格。`validate:ccaof`／`validate:ccarf` で個別）、`npm run build:claude-cert-vocab`（頻出単語の生成）、`npm run test:ccaof-study`（錯題本・移行・資格別キー・バックアップ・考点・予測・シナリオ模試）。

### CCAR-F（Claude Certified Architect – Foundations）

- **大綱**：公式 Exam Guide v1.0（2026年7月発効、試験コード CCAR-F、Anthropic Academy 配布の PDF）に沿う。60 問・120 分・720/1000 合格・受験料 $125・有効 12 か月、5 ドメイン（D1 エージェント設計とオーケストレーション 27%／D2 ツール設計と MCP 連携 18%／D3 Claude Code の設定とワークフロー 20%／D4 プロンプト設計と構造化出力 20%／D5 コンテキスト管理と信頼性 15%）、30 task statement、6 シナリオから 4 つを抽選。出典と確認日は `meta.json` の `sources`・`checkedAt`。**1 シナリオあたりの問題数（約 15 問）は公式に無い推定**で、画面に「非公式・推定」と表示します（`examFormatSource`）。
- **問題**：各ドメイン 80 問、計 400 問（うちシナリオ付き 328 問。type は scenario 299・mcq 53・multi 48）。全問に中国語訳・中文注解・選択肢ごとの解説（日本語）・task statement・公式ドキュメントの出典（platform.claude.com／code.claude.com／anthropic.com）・難易度（1〜3）。問題文はすべてオリジナルで、Exam Guide のサンプル問題は使っていません。
- **シナリオ**：問題にシナリオが付いていると、問題文の上にシナリオの説明（英語＋中国語、たためる）が出ます。トップの「シナリオ別に練習」で 1 シナリオの問題をまとめて解けます。**模擬試験は本番と同じく 4 シナリオを抽選し、シナリオごとに 15 問ずつ**（シナリオの中では配点比率に近づくようにドメインを選ぶ）。
- **讲义**：30 task statement すべて（中国語、用語は英語併記）。
- **頻出単語**：`src/data/claudeCert/ccarf/glossary.json` から 158 語。

## 音声読み上げと音声モード（v1.32.0〜、v1.33.0 から CCAR-F でも）

疲れて読みたくないときに、耳だけで学習を続けるための機能です。ブラウザ標準の Web Speech API（`speechSynthesis`）だけを使い、外部サービス・API キーは使いません（声は端末に入っているもの。多くの端末はオフラインでも読めます）。

- **🔊 個別の読み上げ**：問題文・中文訳・各選択肢・解説・中文注解、頻出単語の単語・意味・中文・例文、讲义の各段の横に🔊。もう一度押すと止まります。英語・日本語・中文は、それぞれの言語の声で読みます。模擬試験の出題中は本番どおり🔊を出しません（結果の「間違えた問題」には出ます）。
- **🎧 音声モード（ハンズフリー）**：画面を見なくても自動で次へ進む連続再生。
  - 頻出単語：単語 → 間 → 意味 → 中文 → 例文 → 単語 → 次の単語（頻出単語の画面の「🎧 音声で聞く」。この範囲／まちがえた単語）
  - 問題：Question 1 → 問題文 → 選択肢 A〜 → 考える間 → 「正解は B」→ 正解の解説 → 中文注解（ドメイン画面の「🎧 音声で聞く」で 20 問ずつ／まちがえた問題、トップの「今日の復習を聞く」）
  - 讲义：概要 → 核心概念 → 正例与反例 → 常见陷阱 → 考试怎么考 → 实务应用 を節ごとに。そのドメインの残りの讲义まで続けて読みます（讲义の「🎧 この讲义を聞く」、讲义一覧の「続けて聞く」）
  - 操作：⏮ 前へ／⏸ 一時停止・▶ 再開（その文の頭から）／次へ ⏭、速度 0.75・0.9・1.0・1.1・1.25 倍、間（短め・ふつう・長め）、読む言語（英語・日本語・中文を ON/OFF）。設定はこの端末に保存され、🔊ボタンの速度にも使います。中文の初期値は「中文訳」の ON/OFF に合わせます。
  - 再生中は画面が消えないようにします（Screen Wake Lock に対応した端末）。iPhone などは画面を消すと読み上げが止まるので、つけたままで使ってください。
- **学習記録への反映**：聞いただけでは「解いた」ことにしません（正答率・弱点・錯題本・合格予測は答えた結果で計算するため）。最後まで聞いた問題・讲义・単語は `ccaofListenV1`（CCAR-F は `ccarfListenV1`）に残り、学習記録の「音声で聞いた」に出ます。頻出単語は `ccaofVocabV1` にも聞いた回数が入り、「学習した単語」「まだ習熟していない単語」に入ります（習熟は変わりません。テストで確かめる流れ）。どちらもバックアップ・リセットの対象です。日をまたいだ全アプリの勉強履歴（📅）は ⭕❌ の回数で記録する仕組みなので、聞いた分は載せていません。
- 音声が使えないブラウザでは🔊を出さず、音声モードの場所に「対応していない」旨を表示します。端末にその言語の声が無いときは「（声なし）」と表示します。
- CCAR-F のシナリオ問題は、シナリオが変わったところでシナリオの説明（英語・中文）を先に読みます。
- 部品：台本づくり `src/claudeCert/audioCore.js`（画面に触らない）、読み上げ `src/claudeCert/speech.js`、画面 `src/claudeCert/CertAudio.jsx`、記録 `src/claudeCert/listen.js`。検証：`npm run test:ccaof-audio`（全 560 問・30 讲义・頻出単語から台本が作れるか、英語の文に日本語・中文が混ざらないか、1 発話 160 字以内、言語 OFF のときの間の引き継ぎ、記録・バックアップ）。

## CCAO-F 対策：考点讲义・考点別の成績・錯題本・合格予測（v1.31.0〜）

「学ぶ → 合格する → 実務で使う」ための 4 機能です。画面のラベルは日本語、讲义の本文は中国語（用語は英語併記）。

- **考点讲义**（トップの「📖 讲义を開く」、ドメイン画面の出題目標の「讲义 ›」）：公式 Exam Guide の 30 objectives ごとに、核心概念（3〜5）・正例と反例・常见陷阱・考试怎么考・实务应用・官方文档。最後の「この考点の問題を解く」で、その objective の問題だけを出題（まちがえた問題 → 未解答 → 解答済みの順に 20 問、または全問）。データは `src/data/claudeCert/ccaof/lessons.json`（id は `D1-1` 形式）。料金・モデル版・上限値などの変わりやすい事実は書かず、公式リンクに任せます。資格レベルの能力（エスカレーション）の問題は `relatedObjectives` で D4-5 から練習できます。
- **考点別の成績と弱点練習**：学習記録画面に 30 考点の正答率・解答数（ドメイン別の表示はそのまま）。問題ごとの記録（`ccaofProgressV1`）から集計するので、これまで解いた分もそのまま反映されます。トップの「弱い 3 考点だけ練習」は解答 5 問以上の考点を正答率の低い順に選び、足りなければ解答の少ない考点で補います（画面に「データ少」「未学習」と表示）。
- **錯題本と今日の復習**：模擬試験・ドメイン練習・考点練習・弱点練習のどこでまちがえても登録（`ccaofMistakesV1`、勉強者ごと）。1日後に出し直し、期限が来てから正解すると 3日後、途中でまちがえて戻った問題は次の正解で 7日後。2回続けて正解で外れます（期限前の正解は数えない）。トップに件数バッジと「今日の復習」。v1.30.0 までの復習リスト（`ccaofReviewV1`）の問題は、初回に錯題本へ移します（ドメイン画面の「復習する」は今までどおり）。
- **合格予測**：直近 3 回の模擬試験の目安スコア（新しいほど重く）と、考点別の正答率を配点で加重したものを 6:4 で混ぜた目安。材料が足りないときは数字を出さず、何が足りないかを表示します。合格 720 まであと何点（約何問）か、次にやること（今日の復習・弱い考点・模試）を 1〜3 行で表示。本番の換算式は非公開なので、合否を保証するものではありません。
- バックアップ／復元・リセットの対象に錯題本を追加。v1.30.0 までのバックアップを戻したときは、復元した復習リストから錯題本を作り直します。
- 検証：`npm run validate:ccaof`（讲义が 30 考点すべてにあるか・必須項目・本文の長さ・公式ドキュメントへの https リンク）、`npm run test:ccaof-study`（間隔・移行・勉強者別キー・バックアップ・考点集計・弱点・予測）。

## CCAO-F 対策：頻出単語（勉強・復習・テスト）

各資格のトップにある「📘 頻出単語」から使います（`src/claudeCert/CertVocab.jsx`）。以下は CCAO-F の例。

- **対象の単語**：全7ドメイン・全問題の設問・資料・選択肢・解説・中文注解から数えた、**4問以上に出てくる単語**（基本語は除く）。出てくる問題が多い順に20語ずつの組に分け、ドメインでしぼりこめます。
- **勉強**：単語カード。意味（日本語・中国語）、発音、実際の問題から取った例文（中国語訳つき、問題IDつき）、どのドメインの何問に出るかを表示し、「覚えた／まだ」を付けます。
- **テスト**：4択（英語→意味／意味→英語）で1回20問。誤答は同じ品詞を優先し、意味が重なる語は使いません。
- **復習**：テストでまちがえた単語・カードで「まだ」にした単語（間違いの多い順）と、まだ習熟していない単語。英検と同じく **2回続けて正解で克服** です。
- 記録は `ccaofVocabV1`（勉強者ごと）。学習記録のバックアップ・リセット・勉強履歴（「頻出単語 テスト／復習」）の対象です。
- データ：意味は `src/data/claudeCert/<資格>/glossary.json` に手で書き、出現回数・出現問題・例文は `node scripts/buildClaudeCertVocab.mjs` で `vocab.json` に生成します。問題を増やしたら作り直してください（`npm run validate` が作り直し忘れを検出します）。

## Sapix（学年 → 科目 → 単元）

アプリ選択画面の「**Sapix**」1 枚から使います（v1.29.0 で科目ごとの 5 枚のカードを 1 枚にまとめました）。中で **学年（1〜6年のうち問題がある学年）→ 科目（算数・国語・理科・社会・英語のうち問題がある科目）→ 単元** の順に選びます。いまは **4年** の 5 科目です。どの学年・科目も同じ画面（`src/SapixApp.jsx`）で、学年・科目の一覧は `src/data/sapix/` のフォルダから自動で作ります（`src/sapixSubjects.js`）。以下は算数の説明で、国語・社会・理科・英語は後ろにまとめています。

### データの置き場所と、学年・科目の追加方法

```
src/data/sapix/
├── README.md          ← 追加手順（下と同じ）
└── g4/                ← 学年（g1〜g6）
    ├── math/          ← 科目：math（算数）/ kokugo（国語）/ rika（理科）/ shakai（社会）/ eigo（英語）
    │   ├── meta.json  ← 単元一覧（grade・subject・分類・単元）
    │   ├── README.md  ← スキーマ
    │   └── <単元id>.json
    ├── kokugo/ ・ rika/ ・ shakai/ ・ eigo/
```

1. `src/data/sapix/g<学年>/<科目>/` を作り、`meta.json` と単元ごとの JSON を置く（形は `g4/` の同じ科目をまねる。`meta.json` の `grade` と `subject` はフォルダ名と同じにする。`eyebrow`・`lead` は画面の見出しと説明、なくてもよい）。
2. `npm run validate` を通す（算数は `validate:sapix-math` で全問を検算、ほかの科目は `validate:sapix-subjects`。フォルダの形・`grade`/`subject` の食いちがいもここで見つかる）。
3. コードの変更はいらない。`meta.json` を置いた学年・科目が自動で画面に出る（学年・科目の画面には、データがあるものだけ出る）。

- **学習記録のキー**：4年は学年別にする前からのキー（`sapixMathProgressV1` など）を**そのまま**使い、それ以外の学年は `sapixG<学年><科目>ProgressV1`（例：`sapixG5MathProgressV1`、復習は `…ReviewV1`）。決め方は `src/sapixStorage.js`。4年のキーを変えるとこれまでの記録が読めなくなるので変えないこと（`npm run test:sapix-storage` で確かめています）。
- **勉強履歴の名前**：4年は以前と同じ「Sapix 算数」など、ほかの学年は「Sapix 5年 算数」など。
- **v1.28.0 からの移行**：学習記録・復習リスト・バックアップの形は変えていないので、移しかえなしでそのまま見えます（ZWJ / ZY / Guest とも）。アプリ選択画面が覚えている「最後に開いたアプリ」が古い値（`sapixMath` など）のときは、自動で `sapix` に直し、その科目（4年）をそのまま開きます。

**算数**：問題は**すべてオリジナル**です。

- **19 単元 × 20 問 ＝ 380 問**：数と計算（計算のくふう・約数と倍数・数のせいしつ・分数の計算）、文章題（和差算・分配算・つるかめ算・植木算・周期算・過不足算・年令算）、図形（角度・三角形・四角形の面積・立体）、規則性・場合の数、速さ・変化とグラフ（速さ・グラフの読み取り・水そうとグラフ）。各単元は基本 8・標準 8・発展 4 の易→難の順。割合・比は使いません。
- **流れ**：単元一覧 → 単元を選んで 20 問 → 1 問ずつ答え合わせ（正解と途中式つきの解き方を表示）→ 結果 → まちがえた問題だけもう一度。単元画面の「まちがえた問題だけ復習」は、端末に残る復習リスト（正解すると外れる）から出題します。
- **答え方**：数値入力が基本（単位つき）。分数は整数・分子・分母の 3 つの欄（帯分数・仮分数どちらでも可。約分わすれは「答えは合っています」と表示して不正解）。曜日・色などは選択肢。図形・規則性の一部は SVG の図つき。
- **学習記録**：単元ごとの正答率・最終学習日・前回の点数を `sapixMathProgressV1`、復習リストを `sapixMathReviewV1` に勉強者ごとに保存。勉強履歴（📅）にも「Sapix 算数／単元名」で出ます。学習記録画面からファイルに書き出し・読み込み（`src/sapixBackup.js`。Sapix の全学年・全科目まとめて書き出し）・リセットができます。英検・CCAO-F の記録には触れません。
- **データ**：`src/data/sapix/g4/math/`（単元ごとの JSON、スキーマは同じ場所の `README.md`）。`npm run validate:sapix-math` で、必須項目・id の一意・各単元 20 問に加えて、**全問の正解を検算式（`calc`）で計算し直して**確かめます。

**国語・社会・理科**（国語 12 単元・社会 15 単元・理科 15 単元、各 20 問 ＝ 840 問、すべてオリジナル）

- **国語**：漢字の読み・漢字の書き（4年の配当漢字を中心に、答えを入力）、慣用句、ことわざ・故事成語、四字熟語、同音異義語・同訓異字、擬態語・擬音語、主語・述語・修飾語、言葉のきまり（つなぎ言葉・こそあど・言葉の種類・敬語）、敬語、読解（説明文・物語文。オリジナルの本文を問題の上に表示）。
- **社会**：地図の見方（方位・地図記号・縮尺）、都道府県と県庁所在地、山地・山脈・火山、川・平野・湖、気候、日本の地名・地形（島・半島・海流）、米づくり、野菜・果物・畜産、水産業、工業、工業地域と太平洋ベルト、伝統工業、森林と林業、くらしを支える（水・ごみ・電気・安全）、自然災害と防災。
- **理科**：植物、こん虫、季節と生き物、蒸散と光合成、食物連鎖・生き物のつながり、動物の分類と骨格、星と星座、月、太陽と影・天気と気温、太陽高度と気温の変化、電気、磁石と電磁石、回路（直列・へい列・いろいろなつなぎ方）、ものの温まり方と体積、水のすがたの変化。
- 選択問題は毎回選択肢を並べかえて出します（順番に意味がある問題をのぞく）。漢字の読みは**ひらがなで入力**（カタカナで入れてもひらがなとして判定）、書きは**漢字で入力**します。
- 学習記録は教科ごとに `sapixKokugoProgressV1` / `sapixShakaiProgressV1` / `sapixRikaProgressV1`（復習リストは `…ReviewV1`）。算数のキーは変えていないので、これまでの算数の記録はそのまま残ります。勉強履歴には「Sapix 国語／単元名」のように出ます。
- **バックアップ**：どの学年・科目の学習記録画面から書き出しても、Sapix の全学年・全科目ぶんをまとめて 1 つのファイル（`sapix-backup-YYYYMMDD.json`）に書き出します。v1.26.0 で書き出した算数だけのファイルも読み込めます。
- **データ**：`src/data/sapix/g4/kokugo/`・`shakai/`・`rika/`（スキーマは各フォルダの `README.md`）。`npm run validate:sapix-subjects` で、必須項目・id の一意・各単元 20 問・難易度の順・選択肢・記述の正解の形・読解の本文の参照を確かめます。

**英語**（10 単元 × 20 問 ＝ 200 問、英検5級〜4級程度、すべてオリジナル。SAPIX の小4 カリキュラムに英語はないため、英検の級を目安にしています）

- 単語（身の回り・数・曜日・月）、単語（動詞・形容詞・前置詞）、be 動詞、一般動詞・3人称単数、疑問詞、現在進行形、過去形、can・will・be going to、会話表現、読解（短い英文。オリジナルの英文を問題の上に表示）。
- 穴うめ・会話・読解は選択式（選択肢は毎回並べかえ）、つづりの問題（曜日・月・動詞の変化形など）は**英語で入力**します。大文字・小文字のちがいは区別しません。解説には日本語訳をつけています。
- 学習記録は `sapixEigoProgressV1` / `sapixEigoReviewV1`。バックアップは Sapix 5教科をまとめて書き出します。データは `src/data/sapix/g4/eigo/`、検証は `npm run validate:sapix-subjects`（国語・社会・理科と同じスクリプト）。

## ⚠️ 重要：Claude Artifacts 専用APIについて（きょうのドリル）

以下は「きょうのドリル」にのみ関係する注意点です（英検マスターはブラウザ標準APIのみで動作するため対象外です）。このコンポーネントは、Claude.ai の Artifacts 実行環境でのみ動作する2つのブラウザAPIを使っています。**GitHub Pages やご自身のサーバーなど、Claude.ai の外で動かす場合は、以下の対応が必要です。**

### 1. `window.storage`（出題履歴の永続化）

各教科の「直近に出た問題」を記録するために使っています。Claude Artifacts 環境では自動的に使えますが、通常のブラウザには存在しません。

- **対応方法**：`window.storage.get / set` の呼び出し箇所（`loadRecency` / `saveRecency` 関数）を `localStorage` や、ご自身のバックエンドAPIに置き換えてください。
- 呼び出しはすべて `try/catch` で保護されているため、置き換えないまま動かしても**エラーにはならず**、出題ローテーション機能だけが無効になります（毎回ランダム出題になります）。

### 2. Anthropic API 呼び出し（カスタム単語・漢字テストのAI生成）

「意味を入力」「穴うめ」「カスタム漢字」テストで、単語の意味・読み・例文をAIに生成させるために、`fetch("https://api.anthropic.com/v1/messages", ...)` を**APIキーなしで**呼び出しています。これは Claude Artifacts 環境がリクエストを自動的に認証・プロキシしてくれる特別な仕組みです。

- **対応方法**：このコードをそのまま外部でホストすると、CORSやAPIキー未設定でこの呼び出しは失敗します。ご自身のサーバー（Node.jsなど）に、Anthropic API キーを使ったプロキシエンドポイントを立て、`fetchWordData` / `fetchKanjiData` 関数の fetch 先をそちらに向けてください。
- こちらも `try/catch` で保護されているため、失敗時は画面にエラーメッセージが表示されるだけで、アプリ全体がクラッシュすることはありません。
- 「聞き取り（ディクテーション）」モードはブラウザ標準の `SpeechSynthesis` API のみを使うため、この制約を受けません。

### 一番かんたんな使い方

上記の理由から、**このコードを一番手軽に動かせるのは、これまで通り Claude.ai の Artifacts（`src/DailyDrill.jsx` の中身をそのまま貼り付け）です。** GitHubはコードのバージョン管理・共有用として使い、実行は引き続き Claude.ai 上で行う、という運用もおすすめです。

### ⚠️ GitHub版とArtifacts版でデータの持ち方が違います

このリポジトリ版（`src/DailyDrill.jsx`）は、理科・社会・国語・英語・英検単語の問題を `src/data/*.json` から読み込む構成になっています（問題を増やしやすくするため。算数のみ数式生成のためJSON化の対象外）。一方、Claude.ai Artifactsにそのまま貼り付けて使う単一ファイル版は、複数ファイルの読み込みに対応していないため、**問題データを引き続きファイル内に直接書いた状態**です。両者は現時点で内容が同期していない場合があるので、混同しないよう注意してください。

        │   ├── 5.json / 4.json / 3.json / pre2.json / 2.json / pre1.json / 1.json

算数以外の問題は `src/data/*.json` に分離されています。**問題を増やしたいときは、コードを変更せずこれらのJSONファイルに追記するだけ**で反映されます。詳しくは `src/data/README.md`（きょうのドリル）・`src/data/eikenApp/README.md`（英検マスターの分野別ドリル）・`src/data/eikenTest/README.md`（英検 模擬テスト）を参照してください。

## GitHub Pagesで公開する

`main` ブランチにpushすると、GitHub Actions（`.github/workflows/deploy.yml`）が自動的にビルドしてGitHub Pagesに公開します。iPad・iPhone・PCなど、どの端末のブラウザからも公開URLでアクセスできます。

- 公開URL：`https://simonwillker.github.io/StudyToolsForZWJ/`
- **初回のみ**、リポジトリの `Settings → Pages → Build and deployment → Source` を「**GitHub Actions**」に設定してください（この設定はGitHub上のWeb画面から行う必要があります）。
- 以降は `main` にpushするたびに自動で再デプロイされます（Actionsタブでビルド状況を確認できます）。
- ローカルのVite設定（`vite.config.js`）には、GitHub Pagesのプロジェクトページ用に `base: "/StudyToolsForZWJ/"` を設定済みです。リポジトリ名を変更した場合はここも合わせて変更してください。
